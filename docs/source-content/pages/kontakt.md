### Responstid

Vi besvarer henvendelser så raskt som mulig, normalt innen:
- E-post: 1-3 virkedager

Husk at vi er frivillige, så det kan ta litt tid i travle perioder!

## Notes for Implementation

When creating this page in WordPress:

1. **Install Contact Form 7**:
   - Go to Plugins → Add New
   - Search "Contact Form 7"
   - Install and activate
   - Create form with fields:
     - Name (text, required)
     - Email (email, required)
     - Phone (tel, optional)
     - Subject (text, required)
     - Message (textarea, required)
   - Add form shortcode to page

2. **Embed Google Maps**:
   - Get Google Maps embed code for club location
   - Add in HTML block or use Maps plugin
   - Center map on club facility
   - Add marker for club location

3. **Add icons** (optional):
   - Email icon next to email addresses
   - Phone icon next to phone numbers
   - Social media icons for Facebook/Instagram
   - Location icon for address

4. **Formatting**:
   - Use columns layout for contact information
   - Create accordion/tabs for different contact types
   - Use call-out boxes for important contacts
   - Add profile images of board members (optional)

5. **Social Media Integration**:
   - Add social media follow buttons
   - Consider embedding Facebook feed widget
   - Link to social profiles

6. **Make it accessible**:
   - Clear heading structure
   - All contact methods easily scannable
   - Mobile-friendly layout
   - Click-to-call phone numbers on mobile
   - Click-to-email email addresses

7. **Keep updated**:
   - Review contact information regularly
   - Update when board/positions change
   - Check that email/phone numbers work
   - Update opening hours seasonally

8. **Add to navigation**:
   - Main menu (top)
   - Footer menu
   - Possibly sidebar widget with quick contact

9. **GDPR Compliance**:
   - Add checkbox for consent in contact form
   - Link to privacy policy
   - Explain how data is used

10. **Auto-responder** (optional):
    - Configure Contact Form 7 auto-reply
    - Thank sender and confirm receipt
    - Set expectation for response time
