# Design Mockups - Elgane Motorsykkelklubb

This directory is for storing design mockups and wireframes for the Elgane website.

## Purpose

Design mockups help visualize the website before implementation and serve as:
- Reference for WordPress theme customization
- Communication tool with stakeholders
- Documentation of design decisions
- Guide for future updates

## What to Store Here

### Mockups (Optional)

**Homepage mockups**:
- Desktop version
- Tablet version
- Mobile version

**Page templates**:
- News/blog list page
- Single news post
- Branch pages (ATV, MX, Speedway)
- Contact page

**Design elements**:
- Header variations
- Footer layouts
- Navigation menu designs
- Button styles
- Color schemes in context

## File Formats

**Image mockups**:
- PNG or JPG for screenshots
- PDF for multi-page mockups
- SVG for vector elements

**Design files** (source):
- Figma (.fig files or Figma links)
- Sketch (.sketch files)
- Adobe XD (.xd files)
- Photoshop (.psd files)

Use clear, descriptive names:

## Creating Mockups

### Tools

**Free tools**:
- **Figma** (figma.com) - Professional, browser-based, free tier
- **Canva** (canva.com) - User-friendly, templates available
- **GIMP** (gimp.org) - Free image editor
- **Inkscape** (inkscape.org) - Free vector editor

**Professional tools**:
- **Adobe XD** - Professional UI/UX design
- **Sketch** - Mac-only design tool
- **Photoshop** - Image editing and mockups

**Simple alternatives**:
- Screenshot existing sites you like
- Hand-drawn sketches (photograph and upload)
- PowerPoint/Keynote (simple layouts)

### What to Include in Mockups

**Layout**:
- Header with logo and navigation
- Content area layout
- Sidebar (if used)
- Footer

**Content**:
- Placeholder text (lorem ipsum or real content)
- Sample images
- Navigation menu items
- Call-to-action buttons

**Branding**:
- Elgane green (#3fb970)
- Dark header/footer (#1a1a1a)
- Club logo
- Typography choices

**Responsive design**:
- Desktop: 1920px width
- Tablet: 768px width
- Mobile: 375px width

## Using Mockups with WordPress

1. **Reference during theme customization**:
   - Use mockups as guide in WordPress Customizer
   - Match colors, fonts, layouts

2. **Show stakeholders**:
   - Get approval before implementation
   - Make changes easier in mockup than in WordPress

3. **Documentation**:
   - Keep mockups as record of design decisions
   - Refer back when making future changes

## Not Required

**Important**: Mockups are **optional** for this project.

Since we're using Astra theme which has good defaults:
- Can skip mockups and customize directly in WordPress
- Use WordPress Customizer live preview instead
- Only create mockups if:
  - You want to plan complex custom layouts
  - Stakeholders need visual approval first
  - You're exploring multiple design directions

## Alternative: Screenshots from Other Sites

Instead of creating mockups, you can:
1. Find motorsport club websites you like
2. Screenshot elements you want to emulate
3. Store screenshots here with notes about what you like
4. Use as inspiration during WordPress customization

Example:
```
mockups/
├── inspiration/
│   ├── club-website-1-header.png
│   ├── club-website-2-news-layout.png
│   └── notes.md (what you like about each)
```
